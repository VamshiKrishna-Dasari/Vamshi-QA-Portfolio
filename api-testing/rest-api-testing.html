REST API Testing

Sample API testing documentation demonstrating request validation, response validation, HTTP status code verification and JSON response checks using a Postman-style approach.

TOOL Postman
PROTOCOL REST
DATA FORMAT JSON
TEST CASES 8 Scenarios

API Request & Response Examples

GET /api/users/101

Request

GET /api/users/101
Accept: application/json

Expected Response

{
  "id": 101,
  "name": "John",
  "email": "john@example.com"
}
Validation: Verify HTTP status is 200, response content type is JSON, and required user fields are present.
POST /api/users

Request Body

{
  "name": "John",
  "email": "john@example.com"
}

Expected Response

{
  "id": 102,
  "name": "John",
  "email": "john@example.com"
}
Validation: Verify HTTP status is 201 and the response contains the newly created resource information.

API Test Scenarios

Test ID Method Scenario Validation Expected Status Status
API_001 GET Retrieve user using a valid user ID. Validate response body and required fields. 200 OK PASS
API_002 GET Request user using a non-existing ID. Validate error response and message. 404 Not Found PASS
API_003 POST Create a user using valid request data. Validate created resource in response. 201 Created PASS
API_004 POST Send request with missing mandatory field. Verify validation error is returned. 400 Bad Request PASS
API_005 PUT Update an existing user's information. Verify updated values in response. 200 OK PASS
API_006 DELETE Delete an existing user. Verify successful deletion response. 200 OK PASS
API_007 GET Send request without required authentication. Verify access is rejected when authentication is required. 401 Unauthorized PASS
API_008 GET Send request using an unsupported HTTP method. Verify appropriate method error response. 405 Method Not Allowed PASS
