QA WORK SAMPLE

SQL & Database Validation

Sample database testing documentation demonstrating SQL queries, CRUD validation, data integrity checks and verification of application data against backend database records.

DATABASE MySQL
TESTING TYPE Database Testing
VALIDATION Data Integrity
SCENARIOS 8 Checks

SQL Validation Examples

SQL_001

Verify User Record

SQL Query

SELECT id, name, email
FROM users
WHERE id = 101;

Expected Result

id     name     email
101    John     john@example.com
Validation: Verify that the database record matches the data displayed by the application.
SQL_002

Verify Newly Created Record

SQL Query

SELECT *
FROM users
WHERE email = 'john@example.com';

Expected Result

A matching user record
should exist in the database.
Validation: Verify that data submitted through the application is correctly stored in the database.
SQL_003

Verify Updated User Information

SQL Query

SELECT name, email
FROM users
WHERE id = 101;

Expected Result

Database values should
match the updated application data.
Validation: Verify that updated application data is correctly reflected in the database.

Database Test Scenarios

Test ID Scenario SQL Validation Expected Result Status
DB_001 Verify user record after creation Search the database using the newly created user's unique identifier. User record should exist with correct values. PASS
DB_002 Verify updated user information Retrieve the updated record using its ID. Database should contain the latest values. PASS
DB_003 Verify deleted record Search for the deleted record. Deleted record should not be returned when hard deletion is expected. PASS
DB_004 Validate mandatory field Check records for missing values in mandatory columns. Mandatory columns should contain valid values. PASS
DB_005 Validate duplicate records Use GROUP BY and COUNT to identify duplicates. Duplicate records should not exist where uniqueness is required. PASS
DB_006 Validate referential data Verify related records between parent and child tables. Related records should maintain valid relationships. PASS
DB_007 Verify record count Compare application records with database count. Application and database record counts should match when applicable. PASS
DB_008 Validate data consistency Compare important UI values against corresponding database columns. UI and database values should be consistent. PASS
