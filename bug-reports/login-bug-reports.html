Bug Reports

Sample JIRA-style defect reports demonstrating clear defect documentation, reproduction steps, expected and actual results, severity and priority classification.

BUG-001
Login button remains enabled when mandatory fields are empty
OPEN
MODULE Login
SEVERITY Medium
PRIORITY Medium
ENVIRONMENT Web Application
TEST TYPE Functional
STATUS Open

Preconditions

User is on the application login page.

Steps to Reproduce

  1. Open the login page.
  2. Leave the username field empty.
  3. Leave the password field empty.
  4. Observe the Login button.

Expected Result

The Login button should remain disabled or appropriate validation should be displayed before submitting the form.

Actual Result

The Login button remains enabled even when both mandatory fields are empty.

BUG-002
Password field does not mask entered characters
OPEN
MODULE Login
SEVERITY High
PRIORITY High
ENVIRONMENT Web Application
TEST TYPE UI / Security
STATUS Open

Preconditions

User is on the application login page.

Steps to Reproduce

  1. Open the login page.
  2. Click inside the Password field.
  3. Enter a password.
  4. Observe the entered characters.

Expected Result

Password characters should be masked using dots or asterisks.

Actual Result

Password characters are displayed as plain text.

BUG-003
Error message is not displayed for invalid login credentials
OPEN
MODULE Login
SEVERITY Medium
PRIORITY High
ENVIRONMENT Web Application
TEST TYPE Functional
STATUS Open

Preconditions

User has access to the login page.

Steps to Reproduce

  1. Open the login page.
  2. Enter a valid username.
  3. Enter an incorrect password.
  4. Click Login.

Expected Result

A clear and appropriate error message should inform the user that the credentials are invalid.

Actual Result

The login attempt fails, but no meaningful error message is displayed to the user.
