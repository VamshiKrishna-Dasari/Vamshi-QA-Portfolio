QA WORK SAMPLE

Login Functionality — Test Cases

Sample test cases demonstrating my approach to functional, negative, validation and boundary testing for a login module.

MODULE Login Functionality
TESTING TYPE Functional Testing
SAMPLE CASES 10 Test Cases
Test Case ID Test Scenario Test Steps Expected Result Type Status
TC_LOGIN_001 Login with valid credentials 1. Enter valid username.
2. Enter valid password.
3. Click Login. 		User should be successfully logged in and redirected to the appropriate page. Positive PASS
TC_LOGIN_002 Login with invalid password Enter a valid username and an incorrect password, then click Login. Appropriate error message should be displayed and login should not be successful. Negative PASS
TC_LOGIN_003 Login with unregistered username Enter an unregistered username and a password, then click Login. Appropriate validation message should be displayed. Negative PASS
TC_LOGIN_004 Username field left empty Leave username empty, enter password, and click Login. Username validation message should be displayed. Validation PASS
TC_LOGIN_005 Password field left empty Enter username, leave password empty, and click Login. Password validation message should be displayed. Validation PASS
TC_LOGIN_006 Both username and password empty Leave both fields empty and click Login. Required field validation messages should be displayed. Validation PASS
TC_LOGIN_007 Password masking Enter a password in the password field. Password characters should be masked. UI PASS
TC_LOGIN_008 Login button behavior Enter valid login details and click Login. Login action should be triggered and the user should proceed to the next page. Functional PASS
TC_LOGIN_009 Password boundary validation Enter passwords at the minimum and maximum allowed length. Application should accept valid boundary values and display validation for invalid values. Boundary PASS
TC_LOGIN_010 Login page navigation Open the login page and verify navigation elements and page loading. Login page should load correctly and navigation should work as expected. UI PASS
